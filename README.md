# Simple Book List App

A clean, responsive, and minimalist book list web application built with vanilla HTML, CSS, and JavaScript. All data is persisted directly in the browser using `localStorage`—no backend, server, or database required.

## Live Demo

🚀 **Experience the app online:** [https://simonui-collab.github.io/booklist/](https://simonui-collab.github.io/booklist/)

## Features

- **Add New Books**: Easily add books with Title, Author, Star Rating (1–5), and Read status.
- **Star Ratings**: Rate books from 1 to 5 stars. Click stars on any book card to update ratings with a single tap.
- **Interactive List**: View your book collection in clean, modern cards.
- **Quick Status Toggle**: Click on any book's status badge to switch between "Read" and "To Read".
- **Edit Books**: Update any book's details in a clean modal window.
- **Delete with Confirmation**: Safeguard your library with a confirmation dialog before deleting.
- **Real-Time Search**: Instant filtering across book titles and authors.
- **Reading Statistics**: Live counters showing Total Books, Read, and To Read counts at the top.
- **Friendly Empty State**: Helpful guidance when your library is empty, with a sample books loader for instant testing.
- **Mobile-First Responsive Design**: Works seamlessly across phone screens, tablets, and desktops.

## Getting Started

No dependencies, build tools, or server setup needed! Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/SimonUI-collab/booklist.git

# Open index.html in your browser
```

## Tech Stack

- **HTML5**: Semantic, accessible markup.
- **CSS3**: Modern CSS variables, responsive flexbox/grid layout, mobile touch targets.
- **JavaScript (ES6+)**: Pure vanilla JS with `localStorage` persistence.
